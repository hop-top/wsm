# THERE IS NO "CS UNPURGE" COMMAND. CS HELP lists PURGE only; UNPURGE returns
# "Unknown command". Un-purging is PURGE DEL.
#
# Syntax (from CS HELP PURGE):
#   PURGE <ADD | DEL | LIST> #channel [code] [reason]
#
# PURGE ADD is a TWO-STEP CONFIRMATION. The first call returns a per-request
# code that must be echoed back. The code must be the SOLE trailing argument:
# appending a reason after the code RESTARTS the confirmation instead of
# completing it. An automated Purge() must therefore parse the code out of the
# NOTICE and re-issue -- it cannot be one fire-and-forget command.
