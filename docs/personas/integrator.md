# Integrator

## Description

A developer who vendors `wsm` as a Go module (`pkg/`) to build workspace capabilities into another tool (e.g., APS). This persona interacts with the `Manager`, `Backend`, and data types directly — never through the CLI. They care about API stability, minimal dependencies, and the ability to implement custom storage backends.
