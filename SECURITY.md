# Security Policy

## Reporting a Vulnerability

Please report vulnerabilities privately to maintainers before public disclosure.

Recommended report content:

- Affected component(s)
- Reproduction steps
- Impact assessment
- Suggested fix (optional)

We will acknowledge receipt and provide a triage update as soon as practical.

## Scope

Security reports are accepted for:

- Core module (`pkg/*`)
- CLI/TUI command handling (`cmd/wsm`, `internal/ui/charm`)
- Storage integrity and migration safety
